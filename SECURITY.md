# Security and responsible use

NomosForge is research software executing finite models supplied by its operator. **It is not audited for production deployment, adversarial tenancy, or public untrusted uploads.** Do not expose it as a policy-decision service without separate security analysis and professional review.

Please report possible security issues privately through the repository's GitHub security advisory feature if available; otherwise open an issue containing only non-sensitive reproduction information. Do not publish credentials, personal records or exploit data.

All initial models are explicitly bounded; fuzzing is an optional research tool. All modeling outputs can still encode biased, mistaken or unlawful assumptions. No computation proves the moral legitimacy or effectiveness of institutional rules in human populations.
