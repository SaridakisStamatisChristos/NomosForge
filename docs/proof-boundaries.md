# Proof and evidence boundaries

The water universe is 3 agents, stock 0..5, need 0..2, critical flag {0,1}; 1,296 worlds. Eight explicit priority operators by reserve {0,1} yield 16 candidate programs. Stock and all allocations are integer tokens. Lexicographic tie-breaking uses input index, so bounded peer disparity is NOT full anonymity.

The two-person one-token impossibility requires strict deterministic anonymity, full utilization, and indivisible integer allocations for that specified symmetric state. It is **not** an inference from grammar failure. Relaxations change the model and are not ranked ethically.

No SMT, empirical human calibration, policy recommendation, or novelty claim is implied.
