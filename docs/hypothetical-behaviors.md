# Strategic response is an assumption, not a verified human fact

`nomos behavior examples/behavior/need-inflation.json` enumerates a small user-declared set of hypothetical need-reporting strategies (truthful, inflating, underreporting).

The true needs used for diagnostic scores are fixed in the input; modeled reported needs may differ, altering allocation. Each observation carries its strategy profile, input report, allocation, shortfall relative to declared true needs, and difference from the truthful baseline.

This is **not** a calibrated human model, probability distribution, verified equilibrium, social prediction, or policy recommendation. A meaningful empirical application requires observational data, validation, uncertainty/sensitivity studies and expert oversight. No arbitrary probabilities or secret citizen attributes are introduced.
