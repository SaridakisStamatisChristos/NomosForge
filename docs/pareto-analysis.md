# Bounded multiobjective reporting

Only policies passing **all** declared hard checks for **every** finite world enter the feasible set.

Metrics: total allocated integer tokens (maximize), maximum per-person shortfall in the bounded domain (minimize), and maximum disparity among citizens with identical declared need/critical class (minimize).

Pareto membership is relative to the finite enumerated candidate grammar and world domain. Equal metric points are retained as distinct nondominated policies. No implicit social-welfare scalar or ethically preferred "winner" is created.

Sensitivity lists, for each named hard axiom, the number of candidate programs feasible if exactly that axiom is removed while all other axioms remain. This is descriptive counterfactual analysis, not a normative recommendation.
