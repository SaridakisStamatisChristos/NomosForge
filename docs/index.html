Institutional rules.
Verifiable assumptions.

Give NomosForge a grammar of proposed rules and explicit constraints. Receive a working policy, a replayable counterexample, or a precisely scoped explanation of which assumptions cannot jointly hold.

Three outputs, three distinct claims

Bounded synthesis

Finds an integer allocation rule satisfying declared checks across 1,296 bounded states.

Conflict evidence

Proves the two-person, one-indivisible-token model cannot be both fully utilized and strictly deterministic-anonymous.

Explicit relaxations

Examines lotteries, divisibility, and waste as model revisions—without inventing a morally preferred trade-off.

Run the two demonstrations

cargo run --quiet -p nomos-cli -- synth examples/water-allocation/world.nomos.yaml --engine enumerate --json /tmp/nomos-policy.json
cargo run --quiet -p nomos-cli -- verify /tmp/nomos-policy.json --full-domain

cargo run --quiet -p nomos-cli -- conflict > /tmp/nomos-conflict.json || test "$?" -eq 3
cargo run --quiet -p nomos-cli -- explain /tmp/nomos-conflict.json || test "$?" -eq 3

What this does not prove

Real-world governance validity is not established. Correct finite models do not validate ethical assumptions, population behavior, demographic classifications, implementation rights, or human responses. CEGIS and model enumeration are established methods; algorithmic novelty and any performance superiority are unverified.
