# Parser fuzz target

Install cargo-fuzz and use `cargo +nightly fuzz run nomos_yaml` from the repository root when a compatible nightly toolchain is available. This target does not run in baseline CI and must not be claimed executed without an observed invocation. Input is arbitrary bytes; valid UTF-8 is passed to the strict YAML model parser. The fuzz seed corpus includes a valid v0.1 model and a duplicate-critical-flags negative case. Normal CI separately runs deterministic malformed-input mutation tests without nightly or cargo-fuzz. Runtime and finding evidence must be reported separately.
